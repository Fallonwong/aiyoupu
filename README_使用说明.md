# AI有谱使用指南

AI有谱帮助你把钢琴乐谱做成跟随音乐演奏的视频。你负责提供素材、选择喜欢的效果，Agent 协助处理制作步骤。

## 安装

1. 从[下载页](https://github.com/Fallonwong/aiyoupu/releases/tag/v2.3.1)下载 `aiyoupu-2.3.1.zip` 并解压。
2. 将解压得到的 `aiyoupu` 文件夹放入当前 Agent 的 Skill 目录。Codex 常见位置是用户目录下的 `.agents/skills/`；其他 Agent 使用各自的技能安装目录。如果不清楚位置，可以让 Agent 帮你查找。
3. 开启新对话，告诉 Agent 使用 `$aiyoupu`。

已有旧版时，先保留原文件夹、工程和作品资料，新版单独安装。

首次使用还需要官方 Remotion Skill。可以让 Agent 检查是否已安装，缺少时再协助安装；已经有的工具和依赖会优先复用。

## 第一次怎么说

复制下面这段，换成自己的素材和要求：

```text
使用 $aiyoupu，帮我制作钢琴跟谱视频。

素材：<乐谱路径>，<录音路径（如有）>。
范围：<全曲，或指定的小节/选段>。
画面：<横屏或竖屏，喜欢的颜色和风格>。

先帮我检查素材是否对应，再展示谱面让我确认。
然后给我看画面和试听，满意后再生成视频。
```

没有明确风格时，可以告诉 Agent「先推荐一个适合这首曲子的方向」。

## 准备素材

- **有 MusicXML**：优先提供它，音高、节奏和声部信息更完整。
- **想保留自己的录音**：同时提供对应乐谱，说明是否有前奏、反复或删节。
- **有 MIDI**：说明左右手和声部怎样分配。
- **只有 PDF 或图片**：提供清晰完整的原件，先识谱再逐小节校对。
- **只有 MP3**：建议补对应乐谱，不能保证只凭录音还原完整双手谱。

乐谱与录音最好属于同一改编、同一选段。同名曲目的不同版本，音符和段落可能不同。

## 确认谱面

Agent 会展示整理后的乐谱。重点检查音高、节奏、休止符、和弦、左右手和连线。

需要修改时，尽量说清楚位置，例如：

> 第 3 小节右手第二个音应为升 F；第 5 小节这两个同音之间是延音线，后一个不要重复弹。

校对完成后，再继续准备配乐和画面。

## 选择画面

可以直接在对话中选择，也可以用可选工作台：

1. 等预览准备好后，对 Agent 说「打开工作台」。
2. 点击预设，调整缩放、焦点等参数，播放或拖动进度查看效果。
3. 满意后点击「保存方向并复制」。
4. 将复制的提示词粘贴回 Agent，继续制作。

工作台用于定方向，不需要在里面再次上传素材或重新识谱。没有音频时，预览会明确显示静音；静音预览不代表最终视频必须无声。

## 试听与生成视频

有录音时可以保留原演奏；没有录音时，可以根据乐谱使用已有钢琴音源准备配乐。

先查看画面和试听，确认风格、运镜、节奏与声音。需要修改时指出具体位置，满意后让 Agent 输出 MP4。

## 已有作品怎么改

直接告诉 Agent 要修改的内容：

- 改音符或节奏：指出小节和音符位置，先核对修改后的谱面。
- 改构图或风格：说明画幅、缩放、颜色或镜头要求，再看更新后的画面。
- 改配乐或音色：提供新录音，或先听新的音色片段。

保留原素材和旧作品，新版本另存，方便比较。
