# 公开找谱分支（AI有谱 V2.1 候选）

当用户只给曲名、尚无对应乐谱时，依次查 IMSLP → Mutopia → PDMX → GitHub → MuseScore → 商业谱库。
前一库未得到匹配版本再进入下一库；记录搜索无结果、访问失败、需登录/付费和排除的候选，不重复暗中换版。
PDMX 是发现入口；仍需核对条目级许可与编配。不得把数据库或网站整体标识当作每份谱的授权。

每次查找维护 `sources.json`：标题、作曲、编配、调性、谱表/声部、页数、小节数、URL、作者、许可、
访问日期、文件 SHA-256、处理结果、排除原因，以及 score/MIDI/audio 版本对应结果。
未下载文件的 fileSha256 为 null，并写原因；失败搜索用查询 URL 或库入口，未知字段为 null，不能虚构作者/许可/哈希。
区分本次实查与从旧报告导入的记录；访问日期不能冒充核验日期。

先核对作曲家和编配，再核对拍号、调性、谱表、音符/重复/小节数及速度时间映射。
速度不同本身不足以证明错版，但对应关系未证实仍须暂停。谱、MIDI、音频不对应时，
标记 version-mismatch / needs-review 并停在版本核对，禁止另一版代替或进入正式谱面审批。
需登录或付费只交链接与选项，不绕过访问限制；无许可证的代码不复制。

找不到匹配谱只能询问用户或提出明确标为试点的回落方案，不冒充权威编配。
公开旋律、试点伴奏、网页乐谱和音源各自的权利状态分别记录，不因 Skill 许可而一并获授权。
两道用户审批保持不变；候选日志不是审批。

来源记录示例见 `examples/sources-v2.json`。示例不宣称完成全部谱库搜索。
